## How it's built

- **Zero cost** — GitHub API + local Hermes state, no paid services
- **Deterministic** — cached per-repo LOC, monotonic counters, deduped token sources
- **Art style** — abyssal-navy canvas, aurora bloom gradients, glass cards, neon series lines
- **Bulletproof cron** — runs every day at 5:30 AM EST, retries on failure, verifies the push landed on remote before reporting success
